## Current target

1. Scale verified C/C++ replacements across `game/engine/` (Telltale core types, containers, math, and embedded Lua 5.x helpers) using the MSVC byte-exact matcher (`tools/verify.py match`) and Win64 live capture/hook-swap runner (`tools/win64_recorder/`).
2. Advance [runtime/](runtime/) past `WinMain` (`USER32.dll` window/message pump, `d3d11.dll` -> Vulkan/GLES renderer bring-up) on `arm64-v8a` Android.

## Recent results

- Implemented and hooked **17** `engine` / embedded Lua 5.x functions (`871` bytes, `7,700+` call sites in `WalkingDead4.exe`): **`16` verified** (edge tests + live-game capture replay + `5` byte-exact under `MSVC 14.44.35207`) and **`1` edge-verified** (`engine_lua_pushunsigned`), all running cleanly in live `twdgame.dll` hook-swap mode inside `WalkingDead4.exe`.
- Expanded [runtime/](runtime/) PAL (`pal.c`, `hooks.c`, `platform_host.c`, `platform_android.c`) with Win32/POSIX/Android semaphores, worker threads, dynamic library loading, executable path resolution, memory allocation, events, file I/O, and UTF-8<->UTF-16 adapters (`62` `KERNEL32.dll` imports + `138` bundled middleware imports = **`200 of 556 (35.97%)`** PE imports mapped).
- Reached boot milestone **`3 of 5` (`WinMain & module/window init`)** in [boot.json](symbols/boot.json), stopping at `USER32.dll::MessageBoxW`.
