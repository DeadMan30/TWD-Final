## Current target

1. Scale verified C/C++ replacements across `game/engine/` (Telltale core types, containers, math, and embedded Lua 5.x helpers) using VS 2017 `v141` (`MSVC 14.16.27023`) byte-exact matching (`tools/verify.py match`) and Win64 live capture/hook-swap (`tools/win64_recorder/`).
2. Implement the Vulkan / OpenGL ES renderer backend (`d3d11.dll::D3D11CreateDevice` -> `arm64-v8a` Android swapchain/device bring-up) and remaining OS/input/networking PAL layers in [runtime/](runtime/).

## Recent results

- Implemented, hooked, and verified **33 / 33** `engine` / embedded Lua 5.x functions (`1,543` bytes, `7,900+` call sites in `WalkingDead4.exe`): **all `33` are `100.00%` byte-exact** (`0` relocations) under VS 2017 `v141` (`MSVC 14.16.27023`), pass live PE edge differential + mutant-kill verification against `WalkingDead4.exe`, and compile/pass under GCC `-std=c11 -O3 -Wall -Wextra -Werror`.
- Expanded [runtime/](runtime/) PAL (`pal.c`, `twd_runtime.h`, `test_runtime.c`) with portable window management & event queue (`twd_window_*`, `twd_alert_box`, `twd_system_metric`), timer period, system info, instruction cache flush, directory enumeration, file truncate/rename/stat, environment/cwd, and UTF-16 helpers (`110` runtime imports across `KERNEL32.dll`, `USER32.dll`, `WINMM.dll` + `138` bundled middleware imports = **`248 of 556 (44.60%)`** PE imports mapped).
- Reached boot milestone **`4 of 5` (`Renderer (D3D11 -> Vulkan/GLES)`)** in [boot.json](symbols/boot.json), advancing past `USER32.dll::MessageBoxW` / window & message-loop init to `d3d11.dll::D3D11CreateDevice`.
