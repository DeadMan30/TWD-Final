## Current target

1. Hook and verify only the critical-path init/render/VFS/loop engine functions needed to reach the main menu (see [BOOT_TRACE.md](docs/BOOT_TRACE.md)), stubbing PC-only Rail SDK, WMI, CrashReporter/Breakpad, and HTTP telemetry.
2. Link upstream/Android libraries (`OpenSSL`, `libcurl`, `Bullet`, `zlib`, `JsonCpp`, Lua 5.2, `FMOD`) and wire the [runtime/](runtime/) Vulkan/GLES swapchain (`twd_gfx_*`), input, and audio lifecycle to `GameActivity` (`arm64-v8a`).

## Recent results

- Hooked and replaced **`37` `engine` functions (`5,606` bytes)**: **`33`** core math/meta/container/Lua C-API helpers (`1,543` bytes) are **`100.00%` byte-exact (`verified`)** under VS 2017 `v141` (`MSVC 14.16.27023`) with live PE edge verification, plus **`4`** PC-only boot/loop stubs (`4,063` bytes: `Rail` SDK, `X-TTG-customercohort` telemetry, PC shell shortcut, Breakpad HTTP upload) cleanly `replaced` in [pc_stubs.c](game/engine/pc_stubs.c); all `37` verified live via Win64 hook-swap (`launcher.exe --swap-dll twdgame.dll`, `4,000 ms` boot smoke run).
- Expanded [runtime/](runtime/) PAL (`pal.c`, `gfx_shim.c`, `subsystems.c`, `android_entry.c`, `platform_android.c`, `twd_runtime.h`, `test_runtime.c`) & [android_main.c](game/android_main.c) with Vulkan/EGL ICD instance/context/swapchain init, DXGI `IDXGIDevice`/`IDXGIAdapter1` COM shims, Android `ANativeActivity` + `AInputQueue` touch/key/gamepad pump, `AAssetManager` loader, frame-loop runner, `arm64-v8a` NDK CI job, and offline PC telemetry stubs (`301` runtime + `138` bundled = **`439 of 556 (78.96%)`** PE imports mapped).
- Cleared all engine-called startup/loop imports in [boot.json](symbols/boot.json), reaching milestone **`5 of 5` (`Audio & GameLoop`, `reached_loop`)** and documenting the main-menu boot trace in [BOOT_TRACE.md](docs/BOOT_TRACE.md).

## Known issues

- `309` thunks in `.text` are intentionally excluded by `tools/ghidra/ExportFunctions.java`; `114` remaining functions (`0.30%`) are currently unattributed in `symbols/source_files.csv`.
- Remaining `117` unbound PE imports are used exclusively by statically linked middleware/CRT (`openssl`, `curl`, `bullet`, `enlighten`, MSVC `crt`) or Breakpad crash reporting, bypassed by linking native Android/upstream libraries instead of decompiling them.
