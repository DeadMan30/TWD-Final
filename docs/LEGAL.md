# Legal

- **No game files, ever.** This repository contains no proprietary game code, executables, DLLs,
  `.ttarch2` archives, extracted assets, decompiler databases, or raw decompiler dumps.
  `tools/check_no_game_data.py` runs in the pre-commit hook and in CI to reject any accidental
  additions.
- **Your own copy.** To verify functions or supply assets for the Android port, you must own a
  legitimate PC copy of *The Walking Dead: The Final Season*. The project never distributes or
  links to game files.
- **No extracted images or media.** Only project-authored diagrams/recordings explicitly listed in
  `docs/assets/ALLOWLIST` are permitted.
- **Not affiliated.** This is an independent fan/preservation project and is not affiliated with,
  endorsed by, or sponsored by Skybound Games, Telltale Games, or AdHoc Studio.
